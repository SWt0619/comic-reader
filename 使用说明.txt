========================================
  本地漫画阅览器 · 使用说明
  打包日期：2026-09-23
========================================

【这是什么】
一个纯本地运行的漫画 / 图片浏览器。无需安装，不联网、不上传任何文件，
用浏览器打开就能阅读硬盘上的图片文件夹。

【文件说明】
index.html                 主入口（需要和下面两个文件放在同一目录）
app.js、style.css          主程序的脚本与样式
comic-reader-single.html   单文件版：HTML / CSS / JS 全部内联在一个文件里
                           ← 单独把这一个文件发给别人也能直接用
使用说明.txt               本文件


========================================
一、怎么用
========================================
1. 用 Chrome 或 Edge 打开（推荐，其他浏览器可能缺功能）
2. 双击 index.html
3. 点「📂 导入文件夹」，选中放着漫画图片的文件夹
   （支持子文件夹，会自动收集 jpg / jpeg / png / webp / gif / bmp）
4. 开始阅读

只想带一个文件走的话，直接双击 comic-reader-single.html，效果一样。


========================================
二、功能
========================================
· 自动翻页（间隔 1–60 秒可调）、随机顺序（两者互相独立，见下）
· 6 种排序、4 种翻页特效、白 / 黄(护眼) / 黑 三种阅读背景
· 显示模式：高度适应（默认）/ 宽度适应 / 原始大小 / 百分比缩放
· 缩略图图片列表、进度条跳转、真全屏
· 自动记住每个文件夹读到第几页，下次打开会提示「继续阅读」
· 最近打开的文件夹列表

快捷键列表（也可以按 ? 打开界面里的同名表格）：
  ← / → / 空格    上一页 / 下一页
  P 或 Enter      自动翻页 开始 / 暂停
  R               随机顺序 开 / 关（只换顺序，不会自动播放）
  T               图片列表 开 / 关
  S               设置面板 收起 / 展开
  F               真全屏（隐藏所有界面，只显示图片；Esc 退出）
  +/-             放大 / 缩小
  W / H / O       宽度适应 / 高度适应 / 原始大小
  0               恢复高度适应
  ?               快捷键说明

鼠标：点击图片左半区/右半区翻页，点中间开始/暂停自动翻页；Ctrl + 滚轮缩放。
      图片列表里滚轮滚动、点缩略图直接跳页。


========================================
三、几个用得着的说明
========================================
1. 显示模式默认是「高度适应」：整页图片完整显示在窗口里（小图不会被放大），
   窗口拉大拉小时会自动重新适配。想按页宽铺满、上下拖着看，就切到「宽度适应」，
   按 W 或 0 之外的模式键（W / H / O）可以随时切换。

2.「真全屏」是彻底的全屏：顶栏、进度条、设置面板、图片列表、底部状态栏
   全部隐藏，屏幕上只剩图片本身，同时尽量进入浏览器全屏。
   进入 / 退出用 F 或点侧栏里的「⛶ 真全屏」按钮，按 Esc 也能退出。
   真全屏下怎么操作（没有常驻按钮，所以用鼠标/键盘）：
     · 点画面正中间 —— 开始 / 暂停自动翻页（也可以按 P 或 Enter）
     · 点画面左侧 / 右侧 —— 上一页 / 下一页（← → 空格 也行）
     · Esc —— 退出真全屏
   真全屏下想看播放状态，把鼠标移到画面最底部（最下面约 100 像素的范围）就会浮出一个
   小提示条，显示「⏸ 自动翻页中 · 每 5 秒一页」或「▶ 已暂停」以及「第几页 / 共几页」；
   鼠标移开、或者 2.6 秒没有操作，它就自动淡出。在画面中间随手动一下鼠标不会弹出提示条，
   不影响看图的干净画面（鼠标静止 2 秒后光标也会隐藏）。
   翻页时（点左右半区、按 ← → 空格、自动翻页、拖进度条）提示条也会立刻收起，不会挡在底部。
   按任意键、或点一下画面中间切换播放 / 暂停时，同样会浮出提示，告诉你当前是播放还是暂停。

3.「随机顺序」和「自动翻页」是两个独立的开关：
   点「随机顺序」只是把图片顺序打乱（页码会显示「随机 x / y」），
   要不要连续自动播放由你自己决定 —— 想播放再点「▶ 自动翻页」。
   同样地，关掉随机顺序也不会顺手把自动播放关掉。

4. 图片列表（按 T 打开）像一个缩略图网格：
   - 缩略图是程序生成的小图，不会把原图整张塞进内存，几百上千张也不会卡；
   - 列表只渲染屏幕上看得见的那几十格，滚动时复用这些格子，滚多远都不掉帧；
   - 左下角小标签是图片序号，鼠标悬停能看到文件名，点一下直接跳过去；点右上角 ✕ 或按 T 关闭。


========================================
四、注意事项
========================================
1.「最近打开」「继续阅读」这类记忆功能依赖浏览器的本地存储，
  数据存在浏览器里，换电脑或清理浏览器缓存后会丢失，
  不影响正常阅读。

2. 用浏览器直接打开本地网页文件（地址栏是 file:// 开头）时，
  部分浏览器会限制网页读取本地文件夹的权限。如果点
  「导入文件夹」没有反应，改用本地服务器方式打开：

     本机装有 Python 的话，在解压出来的文件夹里执行：
         python -m http.server 8000
     然后浏览器访问  http://localhost:8000

  用服务器方式打开时浏览器可以持久记住文件夹授权，体验更完整。

3. 浏览器只读取你选中的那个文件夹里的图片，不会复制、不会上传。
