# 本地漫画阅览器

一个**纯本地**的漫画 / 图片浏览器。零依赖、零安装、不联网：双击 `index.html` 就能读硬盘上的图片文件夹。

- 只用 Chrome / Edge 打开一个本地网页文件即可，**不上传任何文件、没有任何网络请求**
- 想只带一个文件走：用 `comic-reader-single.html`（HTML / CSS / JS 全部内联在一个文件里）

## 特性

| 功能 | 说明 |
|---|---|
| 自动翻页 | 间隔 1–60 秒可调；**与随机顺序互相独立**（随机只换顺序，要不要播放由你决定） |
| 随机顺序 | 打乱播放顺序，页码显示「随机 x / y」 |
| 排序 | 文件名 ↑↓ / 时间 新→旧、旧→新 / 大小 大→小、小→大（共 6 种，文件名走自然序：`3` 在 `10` 前面） |
| 翻页特效 | 淡入淡出 / 滑动翻页 / 缩放淡入 / 无，动画速度 100–1500ms 可调 |
| 阅读背景 | 白 / 黄（护眼）/ 黑 |
| 显示模式 | 高度适应（默认）/ 宽度适应 / 原始大小 / 百分比缩放（25%–400%） |
| 图片列表 | 缩略图网格 + 虚拟滚动：只渲染屏幕内那几十格，几百上千张也不卡；点缩略图直接跳页 |
| 进度条 | 拖动直接跳页 |
| 真全屏 | 隐藏顶栏 / 进度条 / 设置面板 / 图片列表 / 状态栏，屏幕上只剩图片；底部小范围悬停才会浮出状态提示 |
| 阅读记忆 | 自动记住每个文件夹读到第几页，下次打开提示「继续阅读」；另有「最近打开」列表 |
| 大文件夹 | 实测 800 张导入 < 1 秒，滚动列表不掉帧 |

## 快速开始

1. 下载本仓库（`Code` → `Download ZIP`）并解压
2. 用 Chrome 或 Edge 双击打开 `index.html`
3. 点「📂 导入文件夹」，选一个装着图片的文件夹（支持子文件夹，自动收集 jpg / jpeg / png / webp / gif / bmp）
4. 开始阅读

> 用浏览器直接打开本地文件（`file://`）时，部分浏览器会限制网页读取本地文件夹的权限。若点「导入文件夹」没反应，改用本地服务器方式：

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

用服务方式打开时浏览器可以**持久记住文件夹授权**，体验更完整。

### 在线直接用（GitHub Pages）

本仓库根目录就是 `index.html`，到 `Settings → Pages` 选 `Deploy from a branch`、目录选 `/ (root)` 保存后，
就能用 `https://<你的用户名>.github.io/<仓库名>/` 在线阅读了。

## 快捷键

| 按键 | 作用 |
|---|---|
| `←` / `→` / `空格` | 上一页 / 下一页 |
| `P` 或 `Enter` | 自动翻页 开始 / 暂停 |
| `R` | 随机顺序 开 / 关（只换顺序，不会自动播放） |
| `T` | 图片列表 开 / 关 |
| `S` | 设置面板 收起 / 展开 |
| `F` | 真全屏（`Esc` 退出） |
| `+` / `-` | 放大 / 缩小 |
| `W` / `H` / `O` | 宽度适应 / 高度适应 / 原始大小 |
| `0` | 恢复高度适应（默认） |
| `?` | 快捷键说明 |

鼠标：点图片左 / 右半区翻页，点中间开始 / 暂停自动翻页，`Ctrl + 滚轮` 缩放，滚轮滚动图片列表。

真全屏下没有常驻按钮：**把鼠标移到画面底部（最下方约 100px）**会浮出状态提示（正在播放 / 已暂停、第几页），
移开或 2.6 秒后自动淡出；翻页时提示条也会立刻收起。

## 隐私与兼容性

- 只读取你**选中的那个文件夹**里的图片，不复制、不上传；页面**零外部请求**（无 CDN、无统计、无字体外链）
- 浏览记录（读到第几页、最近打开的文件夹）只存在浏览器本地存储里 —— 换电脑或清理浏览器缓存即消失，不影响正常阅读
- 依赖 `showDirectoryPicker` / `createImageBitmap` / `ResizeObserver` / `Element.animate`，推荐 **Chrome / Edge**

想清空本程序的全部记忆，在页面按 `F12` 打开控制台执行：

```js
Object.keys(localStorage).filter(k => k.indexOf('comicReader') === 0)
  .forEach(k => localStorage.removeItem(k));
indexedDB.deleteDatabase('comicReader');
```
