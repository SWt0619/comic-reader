    支持 jpg / jpeg / png / webp / gif / bmp
    请使用 Chrome 或 Edge 浏览器打开本页面

    图片列表 滚轮滚动 · 点击缩略图跳转 · 按 T 关闭

    点画面中间 播放 / 暂停 · 点左右两侧翻页 · P 播放暂停 · Esc 退出全屏
    快捷键
    ← / → / 空格上一页 / 下一页
    P / Enter自动翻页 开始 / 暂停
    R随机顺序 开 / 关（只换顺序，不会自动播放）
    T图片列表 开 / 关
    S设置面板 开 / 关
    F真全屏（隐藏所有界面，只显示图片；Esc 退出）
    + / -放大 / 缩小
    W宽度适应
    H高度适应（默认）
    O原始大小
    0恢复高度适应
    鼠标：点击图片左 / 右半区翻页，中间区域开始 / 暂停自动翻页；Ctrl + 滚轮 缩放。
    随机顺序与自动翻页是两个独立开关：先点「随机顺序」打乱，再点「自动翻页」才会连续播放。
    真全屏（F）下没有常驻按钮：动一下鼠标 / 点一下画面，屏幕底部会浮出提示，显示当前 「自动翻页中 · 第几页」，2.6 秒后自动淡出。
