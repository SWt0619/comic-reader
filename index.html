本地漫画阅览器

导入一个装着图片的文件夹，就能一直翻着读下去

支持 jpg / jpeg / png / webp / gif / bmp
请用 Chrome 或 Edge 打开本页面

    鼠标：点击图片左 / 右半区翻页，中间区域开始 / 暂停自动翻页；Ctrl + 滚轮 缩放。
    随机顺序与自动翻页是两个独立开关：先点「随机顺序」打乱，再点「自动翻页」才会连续播放。
    控制台上每个按钮旁边的小键帽就是它的快捷键。
    真全屏（F）下没有常驻按钮：动一下鼠标 / 点一下画面，画面底部会浮出提示， 显示当前「自动翻页中 · 第几页」，2.6 秒后自动淡出。
